# Universal MCP tool proxy, Godot first

Owner request: expose configured upstream MCP servers as namespaced sub-tools of
chatgpt-mcp, beginning with Godot AI; do not hard-code Godot as the only upstream.

## Contract

- Opt-in proxy.upstreams configuration; no upstreams means unchanged native tools.
- Support stdio, Streamable HTTP, and explicitly selected legacy SSE transports.
- Expose <upstream>.<tool> with original JSON schemas, annotations and content.
- Preserve native computer capabilities; upstream outages must not disable them.
- Reuse upstream connections across stateless downstream requests, bound discovery
  and execution, isolate namespaces, and never automatically replay tool calls.
- Read independent upstream credentials from named environment variables or local
  files. Never forward downstream authentication or expose credentials in status.
- Close owned upstream processes/connections when the server shuts down.
